# Foundation Year Computing Modules Repository

This repository contains all academic materials from my **Foundation Year (Level 3)** at the **Informatics Institute of Technology (IIT), Sri Lanka**, completed before starting the Computing degree affiliated with the **University of Westminster**.

The Foundation Programme builds the fundamentals needed for undergraduate study: **computing, mathematics, programming, academic writing, communication and digital skills**. It includes lecture materials, tutorials, coursework and supporting resources.

---

## 📘 Programme Overview

- **Programme level:** Level 3 (Foundation)
- **Institution:** Informatics Institute of Technology (IIT), Sri Lanka
- **Intake:** January and May 2023
- **Focus:** academic readiness, computing fundamentals and problem solving

## 🛠 Running the Code

The Python programs need only a standard Python 3 installation. Run any script with `python "<file>.py"` from its folder. The one exception is `DOC 333 - Introduction to Programming/Week08_slide12.py`, a lecture example that needs the `mariadb` package (`pip install mariadb`) and a running MariaDB server.
